# Pi

Use the effective `PI_CODING_AGENT_DIR` (normally `~/.pi/agent`). Current native setup uses `models.json`, `auth.json`, `settings.json` and `mcp.json`. Project settings, explicit tool filters and disabled native MCP can override user configuration.

Telos tools use native deferred exposure: discover relevant operations with the available search mechanism before calling the exact returned schema. Keep native file, shell and editing tools. `pi mcp list` checks terminal discovery; `/mcp` shows session status and `/reload` refreshes a running session after reconnection or skill changes.

Preserve permission extensions. Their absence does not imply an automatic approval gate. The shared connector preference policy can be overridden by project `.pi/APPEND_SYSTEM.md`; inspect effective instructions without replacing project work.

Pi has no assumed native curated-memory source. Use only a supported installed extension's selected Markdown/text export. A plain installation may have no memory files to sync.
