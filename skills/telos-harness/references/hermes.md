# Hermes

Inspect the active `HERMES_HOME` and named profile, not just `~/.hermes`. Current shared setup saves a native custom Telos provider and model in that profile's `config.yaml`; ordinary launches use `hermes`. Older isolated staging installations may instead use a Telos provider plugin and its credential pool. Identify which mechanism is active before changing it; do not apply old plugin instructions or patches to current native setup.

Use native MCP discovery and its returned schemas. Tool visibility can differ between deferred discovery and a profile configured by reviewed connector preference. Preserve those settings rather than forcing a universal tool-search mode. Reload the MCP connection or start a fresh chat after recovery; fresh chats also discard retired learned-skill guidance. Existing connector startup policy remains owned by the shared installer.

Native memories are `MEMORY.md` and `USER.md` under the active profile's `memories/`. Keep native memory enabled. Browser grants expire; pooled plugin logout is distinct from revoking a Telos key and does not remove environment overrides.
